# Decisiones de código (ADR)

Aquí se registran las decisiones **técnicas de este repositorio**: por ejemplo, qué librería de rejilla se usa o cómo se maneja el estado. Las decisiones de **producto, alcance, licencias o arquitectura general** se registran en el repositorio de conocimiento `in-depth-knowledge-budget`, no aquí.

## Cuándo escribir una

- Se elige una librería o una tecnología que no estaba decidida (rejilla, enrutador, manejo de datos, generador del cliente de la API).
- Se cambia una regla de `docs/ARQUITECTURA.md`.
- Se toma un camino que el equipo tendría que volver a discutir si no quedara escrito.

**El agente recomienda y el equipo decide** (ADR-007). Una decisión técnica que contradiga una decisión de Victor Manuel va como propuesta en espera (ADR-009) en el repositorio de conocimiento.

## Cómo

1. Copia `0000-plantilla.md` como `NNNN-titulo-corto.md` (número siguiente, cuatro cifras).
2. Llénala. Una página basta.
3. Ábrela en una PR a `development`. Se acepta cuando Victor Manuel o la persona que él designe la aprueba.
4. Una decisión aceptada **no se borra**: si cambia, se escribe una nueva que diga que sustituye a la anterior.
